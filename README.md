# TEK STOCK Desktop

Source code for the TEK STOCK Singapore desktop inventory application.

## Public repository boundary

This repository intentionally excludes installers, production inventory, product mappings, workbooks, local diagnostics, runtime Cloudflare configuration, and credentials. It contains source code, automated tests, a minimal synthetic inventory fixture, representative product images, and a Cloudflare configuration template so external coding agents can reproduce and fix behavior safely.

See [the AI handoff](docs/AI_HANDOFF.md) before changing workbook identity, Excel sync, or update behavior.
